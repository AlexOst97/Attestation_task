# Приложение

Онлайн платформу-торговой сети электроники

# Цель проекта:

Создание веб-приложение с API-интерфейсом и админ-панелью

## Инструкция по установке:

1. Клонировать с GitHab (*git clone https://github.com/AlexOst97/Attestation_task*)
2. Установить зависимости (*poetry install*)

## Функционал приложения:

1. Управление торговыми сетями:
- CRUD-операции (Создание, Чтение, Обновление, Удаление) для объектов торговой сети;
- Объекты сети имеют иерархическую структуру: Завод -> Розничная сеть -> Индивидуальный предприниматель;
- Каждый объект сети может иметь поставщика (вышестоящий объект в иерархии);
- Ведение финансового учета.

2. Управление продуктами:
- Создание и ведение каталога продуктов с указанием названия, модели и даты выхода на рынок;
- Продукты могут быть привязаны к нескольким торговым сетям.

3. Управление контактной информацией:
- Каждый объект сети имеет уникальные контакты (email, страна, город, улица, номер дома);
- Автоматическое проставление времени создания контакта.

4. Финансовый учёт:
- Доступ к API возможен только для аутентифицированных пользователей с использованием JWT-токенов;
- Реализована система permissions, проверяющая, что пользователь активен (IsActive).

5. Административная панель:
- Стандартная Django Admin панель для удобного управления данными (сети, продукты, контакты) администратором.


## Технические требования:

1. Фреймворк: Django 3+
2. API: Django REST Framework (DRF) 3.10+
3. База данных: PostgreSQL 10+
4. Аутентификация: JWT (Simple JWT)
5. Фильтрация: Django Filter
